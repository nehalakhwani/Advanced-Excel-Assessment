# Advanced-Excel-Assessment
This repository contains my Advanced Excel assessment focused on applying Excel formulas and functions to solve real-world data analysis and reporting problems.
The assessment covers lookup functions, conditional calculations, error handling and dynamic filtering.
Excel functions covered:
**VLOOKUP**: Retrieving relevant information from datasets
**SUMIFS**: Calculating totals based on multiple conditions
**MAXIFS**: finding maximum values based on criteria
**AVERAGEIF**: calculating averaged based on conditions
**SUMPRODUCT**: performing multi-condition calculations and weighted analysis
**IF AND**: creating logical conditions and classifications
**IFERROR**: handling errors and improving formula reliability
**FILTER**: extracting records based on conditions
**SUBSTITUTE**: Replacing specific text within cells
**REPLACE**: Replacing characters based on their position
**Key Learnings**:
Applying advanced formulas to business datasets
Cleaning/Transforming data
Handling formula errors
Performing multi-criteria calculations
Extracting data efficiently
Improving accuracy and efficiency
